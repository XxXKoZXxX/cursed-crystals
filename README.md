# 💎 Cursed Crystals — GTA V Criminal Underworld Edition

An immersive 3D web game built with Three.js, WebGL shaders, procedural Web Audio, and GTA V-inspired open-world gameplay.

## 🚀 Live Demos
- **🌐 Vercel Production**: [https://cursed-crystals.vercel.app](https://cursed-crystals.vercel.app)
- **🎮 GitHub Repository**: [https://github.com/XxXKoZXxX/cursed-crystals](https://github.com/XxXKoZXxX/cursed-crystals)

---

## 🌟 Key Features

### 1. ⭐ 5-Star Police Wanted System & Police Pursuits
- **Dynamic Wanted Heat (⭐1 to ⭐5)**: Consuming crystals or crashing into vehicles alerts police.
- **Police Interceptors**: Black & white police cruisers with flashing red/blue lightbars, headlight cones, and siren sound FX.
- **Pay 'n' Spray Safe Houses**: Enterable safehouses to clear your police wanted stars.

### 2. 🏬 Enterable City Stores & Shopping UI
- **24/7 Convenience Store**: Street Pizza, Coffee, Energy Shots.
- **Pharmacy & Dispensary**: Vitamin Boosters, Medical Kits, Sleep Drain Stabilizers.
- **Armory & Hardware**: Kevlar Body Shields, Defense Flares.
- **Pawn Shop**: Trade crystals for mystery packages.

### 3. 🎮 GTA V Style Circular Radar & Visuals
- **Circular Radar Minimap**: Displays red police blips, cyan crystal blips, purple store pads, and player direction.
- **WebGL Lighting & Atmosphere**: PCF soft shadow maps, wet asphalt specular ground reflections, streetlamp volumetric light cones, and multi-faceted glowing 3D gem models.

### 4. 🎵 Web Audio Synthwave Radio
- Built-in multi-track synthesizer generating a cyber-noir soundtrack with drum beat, bassline, and arpeggios.

## 🛠️ Local Development

Open `index.html` directly in any web browser or serve with Python:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.
